# libwebgrep Feature Matrix & Security Boundaries (`v0.10.0`)

[English](FEATURES.md) | [简体中文](FEATURES.zh-CN.md)

`libwebgrep` (`v0.10.0`) is a high-performance, embeddable text and regular expression search engine written in pure **Zig `0.17.1`** with zero external dependencies and no `libc` requirement.

---

## 2. Hard Security & Architectural Boundaries

1. **Zero External Processes**: Never calls `execve`, `posix.spawn`, or external decompression binaries.
2. **Zero Backtracking Regex**: Never uses backtracking regex engines or PCRE bindings; every regex executes in strict $O(n)$ time via `UnanchoredDfa` / `SetUnanchoredDfa` / `LazySetDfa` / `BoundedDfa` + Thompson NFA / PikeVM.
3. **Path Traversal & Symlink Safety**: Public service search entry points (`searchSource`, `searchSourceSlice`, `resumeSourceSlice`, `openSourcePull`, `openReaderPull`) never accept filesystem paths; `ArchiveTree` and `source.Memory` reject `..` / Zip-Slip path traversal and skip symlinks; directory traversal disables symlink following by default (opt-in `--follow` enforces `file_id.zig` inode/device cycle guards) and never reads global host configuration.
4. **Zero Host CPU Probing**: Concurrency is strictly governed by caller-supplied `max_concurrency` rather than probing host CPU cores.
5. **Zero Unbounded Buffering**: Events are streamed as each line and source completes; `libwebgrep` never buffers unbounded result sets in memory, and leaves terminal colorization and NDJSON wire serialization to the caller.
